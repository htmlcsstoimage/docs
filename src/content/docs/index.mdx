Generate images and PDFs from HTML/CSS, take screenshots of webpages, or create thousands of images from a single template. We run the browsers so you don't have to.

- Get back a `png`, `jpg`, `webp`, or `pdf`
- Use your own fonts, CSS, and JavaScript
- Reuse templates with different text, images, and data
- Automatically generate Open Graph images for every page on your site
- Works with your code, automation tools, and AI assistants
- No janky fonts or blurry images

## Four ways to generate images

<div className="generation-grid">
<ExampleCard
  id="from-htmlcss"
  title="From HTML/CSS"
  description="Send HTML and CSS to render an image or PDF. Use your own layouts, fonts, and JavaScript."
  href="/getting-started/using-the-api/"
>

```http wrap
POST https://hcti.io/v1/image

{
  "html": "<h1>Hello world</h1>",
  "css": "h1 { color: #00b980; }"
}
```

</ExampleCard>
<ExampleCard
  id="from-any-url"
  title="From a URL"
  description="Screenshot a public webpage, capture the full page, or crop to a specific element."
  href="/getting-started/url-to-image/"
>

```http wrap
POST https://hcti.io/v1/image

{
  "url": "https://example.com",
  "full_screen": true
}
```

</ExampleCard>
<ExampleCard
  id="from-templates"
  title="From a template"
  description="Design a template in the visual editor or with HTML/CSS, then generate images with different text, images, and data."
  href="/getting-started/templates/"
>

```http wrap
POST https://hcti.io/v1/image/TEMPLATE_ID

{
  "template_values": {
    "title": "Hello world"
  }
}
```

</ExampleCard>
<ExampleCard
  id="automatic-open-graph-images"
  title="Automatic Open Graph images"
  description="Connect your website or CMS and generate a social card for each page from its screenshot or metadata."
  href="/getting-started/og-images/"
>

```html wrap
<head>
  <meta
    property="og:image"
    content="https://hcti.io/v1/og/DOMAIN_ID/"
  >
</head>
```

</ExampleCard>
</div>
