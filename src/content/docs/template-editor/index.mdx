Build a reusable image template in the dashboard, preview it with sample data, and save it for rendering through the API. Choose the visual block editor to arrange your design on a canvas, or the HTML/CSS code editor to work directly with markup and styles.

## Choose an editor

1. Open **Templates** in the dashboard.
2. Click **Create New Template**.
3. Under **How would you like to build?**, choose the editor that fits your workflow.

<DocImage preset="screenshot" src="/assets/images/template-editor/te-editor-choice.png" alt="New template screen offering the Block editor and Code editor" caption="Start with blocks to build visually, or start with code to write HTML and CSS." />

| Editor | Choose it when | Start here |
|:-------|:---------------|:-----------|
| **Block editor** | You want to build visually with text, images, shapes, and layout panels. | [Visual editor quick start](/template-editor/quick-start/) |
| **Code editor** | You want to write HTML and CSS, or edit an HTML/CSS template you already created through the API. | [HTML/CSS editor guide](/template-editor/html-css/) |

For an existing template, click its pencil button, **Edit template**. Entries marked **BLOCKS** open in the visual editor; entries marked **HTML/CSS** open in the code editor. **Duplicate template** starts a copy that gets its own template ID when saved.

## What you can build

- Social sharing images, product graphics, certificates, reports, and cards
- Reusable layouts that generate different images from new text, image URLs, and other data
- Saved templates for API requests, signed URLs, or [automatic Open Graph images](/getting-started/og-images/)

## Build visually with the block editor

Add blocks, arrange them on the canvas, and style them using the sidebars. Connect fields to variables when their values should change for each image.

Start from a blank template, browse the [template presets](https://htmlcsstoimage.com/templates), or try the [template playground](https://htmlcsstoimage.com/templates/playground).

<DocImage preset="screenshot" src="/assets/images/template-editor/te-quote-preset-editor.png" alt="Visual block editor with the quote preset open on the canvas" />

### Editor areas

| Area | What it controls |
|:-----|:-----------------|
| Canvas | Image size, canvas background, image settings, and the visible template area |
| Left sidebar | Blocks you can add to the template |
| Right sidebar | Properties for the selected canvas, block, panel child, or variable |
| Variables tab | Preview values and variable behavior before rendering |
| Preview and export | Check the generated output while you work |

Follow the [visual editor quick start](/template-editor/quick-start/) to build your first template.

## Write HTML and CSS with the code editor

Edit your markup and styles in separate **HTML** and **CSS** tabs alongside a live preview. Use **Variables** to test Handlebars values, and **Options** to configure viewport dimensions, fonts, capture settings, and delivery options.

The code editor opens existing HTML/CSS templates created through the API, so you can continue working on them in the dashboard. Click **Save** to persist your changes.

Follow the [HTML/CSS editor guide](/template-editor/html-css/) for a complete example, preview controls, and the save workflow.

## How it fits with the API

Both editors save reusable templates. After saving, use the template ID and pass `template_values` when generating images.

Use the same [template rendering API](/getting-started/templates/#creating-an-image-with-a-template) for either type. You can also create [signed template URLs](/getting-started/create-and-render/#creating-a-templated-image-url).

For creating and updating templates programmatically, see the [templates API reference](/getting-started/templates/).
