Use Shape blocks for marks, backgrounds, accents, and decorative structure. Add one from the left sidebar and choose the shape when you add it.

<CommonBlockOptions kind="shape" />

## Shape types

- Rectangle
- Circle
- Triangle
- Star

The type cannot change after creation. Add a new Shape block when you need a different type.

## Block-specific properties

| Property | Details | Variables |
| --- | --- | --- |
| Opacity | Transparency of the whole block, including content and styling. | Yes |
