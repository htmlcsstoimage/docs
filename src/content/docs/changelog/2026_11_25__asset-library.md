You can now upload logos, fonts, stylesheets, and other files to your organization’s **Asset Library**. Each file gets a reusable URL. Copy the image tag or font rule from the dashboard into your design, then preview it in the Image Console.

Uploads default to **HCTI only**, so you can share a finished image while keeping the source file private. Choose **Public** if you also want to use the file in a local preview or another tool. When you replace a file, its base URL stays the same. Copy the updated snippet to pick up the new version on your next render.

You can also upload and manage files through the [Assets API](/management-api/assets/) or have a connected assistant find and reuse them with the [MCP asset tools](/integrations/mcp/tools/#asset-library).

[Open your Asset Library](https://htmlcsstoimage.com/dashboard/assets) or [follow the upload guide](/getting-started/uploading-assets/).
