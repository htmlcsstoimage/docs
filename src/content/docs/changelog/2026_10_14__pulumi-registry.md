The official HTML/CSS to Image provider is now available in the [Pulumi Registry](https://www.pulumi.com/registry/packages/html-css-to-image/), with installation instructions and API references for every resource and lookup.

Manage images, templates, API keys, proxies, storage destinations, and Open Graph configurations using TypeScript, Python, Go, C#, Java, or YAML. Connect HCTI resources to the rest of your infrastructure: provision an S3 bucket and its trust policy, register it as an image storage destination, or pass a scoped API key directly to your application's secrets manager.

Start with our [Pulumi guide](/management-api/pulumi/) for examples, or browse the [complete API reference](https://www.pulumi.com/registry/packages/html-css-to-image/api-docs/).
