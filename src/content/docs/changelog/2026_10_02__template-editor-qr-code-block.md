Add scannable URLs or text to your templates with the new **QR Code** block. Choose **QR Code** in the Template Editor's left sidebar, then enter the content in the right sidebar. Connect Content to a variable to generate a different QR code for each image through `template_values`.

Customize the foreground color and background, choose from four error correction levels, and adjust the quiet zone around the code. New blocks start with black modules on a white background, Medium error correction, and a four-module quiet zone.

See the [QR Code block documentation](/template-editor/blocks/qr-code/) for controls, sizing guidance, and an example using variable content.
